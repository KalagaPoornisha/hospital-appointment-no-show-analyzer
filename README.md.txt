Hospital Appointment No-Show Analyzer

Project Overview

This project analyzes hospital appointment data using Power BI to understand patient attendance and identify patterns associated with missed appointments.

Objectives

Analyze total, attended, and missed appointments.

Explore appointment patterns across different age groups.

Examine SMS reminder distribution and its relationship with missed appointments.

Tools Used

Power BI

Power Query

DAX

Dashboard Features

Total Appointments

Attended Appointments

Missed Appointments

Average Waiting Days

Appointments by Age Group

No-Show Rate by Age Group

SMS Reminder Distribution

Key Learnings

Data cleaning and transformation using Power Query.

Creating calculated columns and measures using DAX.

Building interactive dashboard visualizations in Power BI.
